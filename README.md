# Lista de produtos com filtros

Projeto de estudo em HTML, CSS e JavaScript para praticar a criação dinâmica de elementos, a filtragem de arrays e o cálculo do valor total dos produtos exibidos.

## Funcionalidades

- Exibe nove produtos organizados por categoria.
- Filtra por Hortifruti, Padaria e Laticínios.
- Pesquisa por nome ou categoria.
- Atualiza o total conforme os produtos exibidos.
- Adapta a apresentação a telas pequenas.
- Permite executar a pesquisa pelo botão ou pela tecla Enter.

## Como executar

Abra `index.html` em um navegador. O projeto não requer instalação de dependências nem conexão com banco de dados.

## Verificação manual

1. Confirme que a lista inicial mostra nove produtos e totaliza R$ 57,00.
2. Selecione cada categoria e confira três produtos e o total correspondente.
3. Pesquise por `bolo` usando o botão e a tecla Enter; ambos devem mostrar um produto e R$ 10,00.
4. Navegue pelos filtros e pela busca usando a tecla Tab e confirme que o foco está visível.
5. Redimensione a janela para 320, 375, 768, 1024 e 1440 pixels e confira que não há rolagem horizontal.
