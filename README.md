# Lista de produtos com filtros

Projeto de estudo em HTML, CSS e JavaScript para praticar a criação dinâmica de elementos, a filtragem de arrays e o cálculo do valor total dos produtos exibidos.

## Funcionalidades

- Exibe nove produtos organizados por categoria.
- Filtra por Hortifruti, Padaria e Laticínios.
- Pesquisa por nome ou categoria.
- Atualiza o total conforme os produtos exibidos.
- Adapta a apresentação a telas pequenas.

## Como executar

Abra `index.html` em um navegador. O projeto não requer instalação de dependências nem conexão com banco de dados.
